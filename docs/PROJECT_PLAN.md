# GhostRoom

## Vision

GhostRoom is a privacy-first temporary chat application.

Users can create a room or join an existing room using a six-digit code. No account is required. Rooms are temporary and disappear after they expire or everyone leaves.

## Version 1 Features

- Create Room
- Join Room
- Six-digit room code
- Anonymous usernames
- Temporary rooms
- Real-time messaging
- End-to-end encryption (planned)
